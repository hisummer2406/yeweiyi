# 协议文档

液位仪对接的各类串口 / 网口协议。除 `对外Modbus对接说明.docx` 是本项目编写的，其余都是厂家或历史提供的原始文档，文件名保持原样（代码注释和单测按原名引用）。

## 对外（液位仪作为从站，给 PLC / SCADA / 后台读数据）

| 文档 | 内容 | 对应代码 |
|---|---|---|
| `对外Modbus对接说明.docx` | **给客户的对接文档**，以液位仪当前实际行为为准：串口 + 网口 5020（RTU over TCP / 标准 Modbus TCP）、寄存器表、报文示例 | `factory/ZhongChengModbusSlave`、`ModbusTcpServer`、`ModbusTcpFraming` |
| `中成液位mobus协议.docx` | 上一份的原始依据：从站地址 8、功能码 03、每罐 6 个 float | 同上 |
| `维德路特协议，VR协议.doc` | VR（维德路特）SS160 控制器后台通讯协议，串口 5 收到 `i20100` 查询时按此应答 | `factory/VR350Factory.backOilcanData` |

对外 Modbus 的字节序、高度单位、寄存器地址以 `对外Modbus对接说明.docx` 为准；原始文档的文字描述与举例有不一致处。

## 探针（液位仪作为主站，读探针）

| 文档 | 内容 | 对应代码 |
|---|---|---|
| `新版中成探针协议.doc` | 中成探针（`FE FE` 帧）：查询液位（功能码 44）、温度（45） | `factory/ZhongChengCompany` |
| `协议探针长度查询.doc` | 中成探针长度查询，含地址 1~12 的查询码 | `ZhongChengCompany.sendChangDuInfo`，单测 `ZhongChengAddressTest` |
| `雷达液位计标准modbus协议.pdf` | 80GHz 雷达物位计 Modbus RTU（读料高：`03 0002 0002`，单位 mm） | `factory/LDCompany`（串口设置选"标准 Modbus"） |
| `数字量输入输出系列使用手册(RS485&RS232版).pdf` | 中盛 IO 模块 Modbus RTU（功能码 04 读输入寄存器），用于 4-20mA 采集 | `factory/LD2Company`（选"4-20mA"）；手册没写模拟量值的单位，代码里的换算无法从文档核实 |

## 外设
