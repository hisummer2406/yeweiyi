## Purpose

修正 `rewrite-stock-inout-detection` 引入的"未同时满足双阈值时持续观察"规则：把"继续等待"限定在"时长阈值尚未达标"这一种情况，"时长已达标但高度不够"改为立即放弃，不再依赖 `maxTrackingMillis` 兜底。以下 Requirement 均为对该变更引入的同名 Requirement 的修改（MODIFIED），未提及的 Requirement（死区容差、方向只判定一次、记录开关、可脱离 Context 单测等）不受影响，沿用原文。

## MODIFIED Requirements

### Requirement: 出/入库记录只在时间阈值与高度阀值同时满足时生成
一次液位变化，从开始偏离基准到稳定不再变化的持续时长达到对应方向的时间阈值（`InTime`/`OutTime`），且净高度变化达到对应方向的高度阀值（`InHight`/`OutHight`）时，SHALL 生成对应方向的出/入库记录。任一阈值未满足时，SHALL NOT 生成记录；两者未满足时的后续处理不对称，见下方各 Scenario。

#### Scenario: 两个阈值都满足
- **WHEN** 某罐液位从基准值持续变化后趋于稳定，净变化量 ≥ 该方向高度阀值，且从开始变化到稳定的时长 ≥ 该方向时间阈值
- **THEN** 生成一条对应方向（入库或出库）的记录，起止高度、起止时间与本次变化一致

#### Scenario: 液位已确认稳定、时长阈值已达标，但这个稳定值对应的高度阀值不够
- **WHEN** 液位已经真正稳定（持续超过去抖窗口，而不是任意一次尚未确认稳定的读数），且从开始变化到当前的时长已 ≥ 该方向时间阈值，但这个已确认稳定的净变化量 < 该方向高度阀值
- **THEN** 不生成记录；判定逻辑 SHALL 立即放弃该段跟踪，并以当前稳定的液位重新建立基准，不再继续等待后续可能的变化

#### Scenario: 高度阀值已达标，时长阈值不够
- **WHEN** 净变化量已 ≥ 高度阀值，但从开始变化到当前的时长 < 时间阈值
- **THEN** 不生成记录，且不丢弃已跟踪的起点信息——继续观察，等待时长达标或液位继续变化（沿用 `rewrite-stock-inout-detection` 的原有行为，本次未改动）

### Requirement: 时长阈值未达标时持续观察，不因高度尚未达标而提前放弃
判定逻辑在液位稳定但时长阈值尚未达标时，无论此刻净变化量是否已经达到高度阀值，SHALL 保留已跟踪的起点（起始高度、起始时间），并在后续读数到来时重新检查，而不是因为"当前高度不够"就提前清空跟踪状态。一旦时长阈值达标，是否继续跟踪则完全取决于高度阀值是否也已达标（见上一条 Requirement）：达标则产出记录，不达标则立即放弃，不再有"继续观察"这一步。

#### Scenario: 稳定后第一次检查未达标，之后时长自然追上
- **WHEN** 液位变化后趋于稳定，第一次稳定检查时时长尚未达到时间阈值（此时净变化量是否已达标不影响本场景的处理方式）
- **AND** 液位持续保持该稳定值，后续读数到达时点距开始变化的时长已达到时间阈值
- **THEN** 在时长达标的那次读数上，按当时净变化量是否达标决定产出记录或立即放弃——起止高度均与最初那次变化一致

#### Scenario: 时长未达标期间液位又开始变化，视为同一段事件的延续
- **WHEN** 处于"时长未达标、继续观察"状态时，液位又发生了超出噪声容差的变化
- **THEN** 判定逻辑继续跟踪同一段事件（起始高度/起始时间不变），而不是当作新的一段变化重新起算

### Requirement: 时长阈值本身迟迟凑不够时兜底放弃跟踪
一段跟踪从开始变化起持续超过一个预设的最长跟踪时长，若此时连时长阈值本身都还未达标，SHALL 放弃该段跟踪并以当前液位重新建立基准，避免时间阈值配置得不合理地大导致状态无限期悬挂。若时长阈值已经达标，是否继续跟踪由高度阀值是否达标直接决定（见上文），不会再走到这条兜底。

#### Scenario: 时长阈值配置过大，长期凑不够
- **WHEN** 从开始变化起的时长长期低于时间阈值（例如时间阈值配置得异常大）
- **AND** 从开始变化起的时长已超过预设的最长跟踪时长
- **THEN** 放弃该段跟踪，不生成记录，且后续判定以当前液位作为新的基准重新开始

#### Scenario: 一段跟踪内方向来回反转，最终净变化被抵消到不够阈值
- **WHEN** 某罐液位在同一段跟踪期间发生过超出高度阈值的上涨、又发生超出高度阈值的下跌（或反之），中途从未真正稳定超过去抖窗口且同时凑够双阈值
- **AND** 时长阈值达标时，最终稳定值相对最初起点的净差低于对应方向高度阀值
- **THEN** 判定逻辑在时长达标的那次读数上立即放弃该段跟踪、不生成任何记录，并以最终稳定值重新建立基准；不会等到 `maxTrackingMillis` 才放弃，也不会把之后不相关的液位变化并入这个已经放弃的起点
