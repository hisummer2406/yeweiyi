## Purpose

防止局域网内未登录的第三方直接调用设备本机 HTTP 接口读取或修改数据，为 `device-write-back-sync` 即将上线的写接口提供鉴权基础。

## ADDED Requirements

### Requirement: 登录成功后签发访问令牌
`/login` 校验成功后，设备 SHALL 签发一个有时效的访问令牌，并在响应中返回给调用方。

#### Scenario: 用户名密码正确
- **WHEN** 调用方提交正确的用户名和密码
- **THEN** 响应中包含一个新签发的访问令牌，且该令牌在有效期内可用于后续请求

### Requirement: 数据类接口必须校验令牌
`/alarm`、`/oilDischarge`、`/baseOilcan`、`/upload` 及后续新增的写接口 SHALL 要求请求携带有效令牌，缺失或令牌无效时拒绝请求。

#### Scenario: 未携带令牌访问报警查询接口
- **WHEN** 调用方在没有携带任何令牌的情况下请求 `/alarm`
- **THEN** 设备拒绝该请求，不返回任何报警数据

#### Scenario: 携带过期令牌
- **WHEN** 调用方携带一个已超过有效期的令牌发起请求
- **THEN** 设备拒绝该请求，视同未携带令牌

### Requirement: 令牌过期后需要重新登录
访问令牌 SHALL 有明确的有效期，过期后该令牌不再被任何接口接受，调用方必须重新调用 `/login` 获取新令牌。

#### Scenario: 令牌过期后继续使用
- **WHEN** 调用方使用一个已过期的令牌请求任意受保护接口
- **THEN** 该令牌不会被接受，即使它此前是有效的
