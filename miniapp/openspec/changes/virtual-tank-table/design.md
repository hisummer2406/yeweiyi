# 设计

核查基线：main `efda7f0`。设备口径依据 `android/.../factory/LDCompany.java`（各探针解析同理）、`utils/DataUtils.java#getVoulme`、
`android/docs/ThingsBoard两版迭代执行方案.md`（oilVolumeL 含水说明）。

## 设备口径（已核实）
- `oilLevelMm` 是总液面高度；`oilVolumeL` = 用该高度查设备罐表得到的**总体积（含底水）**，不扣水。
- `oilWeightKg` = `oilVolumeL` × 密度设置（g/cm³ = kg/L，无温度补偿），设备各自取 1 位小数。
- `nullVolumeL` = 容量 − 总体积；`waterVolumeL` 在真实探针模式下恒为 0；`oilRatioPct` = 液位/罐高，与罐表无关。
- 设备查表：低于首点取首点容积，两点之间线性插值，高于末点用最后一段外推。

## 虚拟显示计算（`utils/virtualTable.ts`）
数据链路：设备上报液位 → 当前账号为该设备该罐启用的**完整**虚拟表 → 容积。不使用预览抽样、不按满罐容量比换算。
- 查表 `lookupVolume`：液位缺失/非数字 → `missing`；负数或高于末点 → `range`（**不外推、不截到满罐**，与设备外推不同，按 #56 要求）；
  0 → 0；0 与首点之间按 (0,0)–首点线性；命中表点取该点；两点之间分段线性。液位直接用上报值，不再叠加液位修正。
- 派生（与设备同口径，只换罐表）：
  - 容积 = V虚(液位)；
  - 质量 = V虚 × 设备有效密度，有效密度 = 原质量 ÷ 原容积（同一快照、未舍入的原始值，未经任何倍率）；原容积不是正数时质量缺失（显示「—」），V虚 = 0 时质量为 0；
  - 空容 = 虚拟表末点容积 − V虚；
  - 水体积 = V虚(水高)；水高缺失时保持设备值；
  - 液位、水高、温度、占比、罐图填充保持设备值。
- 液位缺失或越界：四项全部回退设备原值并标「设备原值」及原因，不混用两张表。
- 每次从 `raw`（未舍入原始值）重算，重复应用不叠加；停用即回到设备值。
- 已知边界：截图示例表末点 2599 mm，设备上报 2600 mm（满罐）时属越界，显示设备原值并说明。

## 存储与权限（实施假设，沿用 #44 范围）
- key = `virtual-table:<账号 uid>:<完整设备编号>#<实际罐号>`，值 `{shape, dims, heightMm[], volumeL[], enabledAt}`（完整表，≤2000 点）。
  读回校验：≥2 点、等长、有限、液位严格递增且 >0、容积不减；不合格当未启用。
- 角色与账号每次从 token 取：仅 `platform_admin`/`customer_admin` 可启用、停用、应用；员工与无 role 看设备原值，也看不到启用入口和本机虚拟表区块。
- 登出不清（key 含账号）；换账号读不到；换机后设备编号不同自然不生效；同设备不同罐、不同设备同罐号互不影响。
- 写入失败提示「保存失败，未启用」；停用删除失败提示失败。

## 交互
- `tank-shape-edit`：生成后结果区出现「启用为虚拟罐表」（仅管理员）→ 读首页当前油站设备与可见罐 → 选罐（与下发共用罐号面板，标题不同）→
  确认框（设备、罐、点数/末点，说明只在本机、不改设备）→ 用同一尺寸重新生成完整表并保存。确认期间改了尺寸则不启用。
  修改尺寸只让预览作废，已生效的虚拟表不受影响，直到新表启用替换。「保存到控制器」照旧要求原因、走 `configSubmit`。
- `tank-shape`：「设备当前罐表」下方「本机虚拟罐表」：所选罐的罐型与尺寸、点数/末点、启用时间、替换说明、「停用」。
- 首页罐卡：「虚拟罐显示」/「设备原值」徽标；罐详情：同徽标 + 说明 + 各项下方「设备原值 x」。
- 旧倍率：首页 `onShow` 若当前账号还有 `display-scale:` 记录，删除并弹一次说明。

## 数字键盘（`components/param-editor`）
- 所有数值框 `type="digit"`。带符号字段：输入框只放数值部分（`splitSigned`），负号由 ± 切换、显示在框前；键盘输入用 `joinSigned` 接回原符号；
  输入法若能打出「-」以打出的为准。清空保留单独「-」，不补 0；`buildArgs` 照旧拒绝 `-`、`1.` 等不完整值。下发原因仍是文字键盘。
- 独立「参数修正」页与罐详情页签共用组件；储罐设置中带符号字段同样处理。

## 首页排版
- `.hs-value` 字号随 `.hs-label`（常规 `--font-body` 30rpx，短屏 `--font-label` 28rpx），字重 normal，`white-space: nowrap`；
  去掉行的 290rpx 上限，数值列约 222rpx（等宽数字约 13 位），单位列最小 40rpx。不截断、不省略、不改精度。
