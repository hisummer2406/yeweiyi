# 虚拟罐表替代显示倍率；修正数字键盘；首页读数排版（Issue #56）

## Why
- 用户认为统一乘倍率得到的容积不准确，决定下线 #44 的显示倍率，改为在「罐表设置」生成另一张罐表（虚拟罐表），手机按设备上报的液位在这张表上查出容积显示。例：现场显示器用约 20000 L 的表，手机用卧罐 H=2600/L=5000/R=500 生成的 260 点、末点 2599 mm / 30086 L 的表。
- 「参数修正」三个数值框弹出的是文字键盘，需先切到数字。
- 首页读数比左侧标签大且粗，长读数（如 24344.25）被拆成两行。

## What Changes
- **下线显示倍率**：删除罐详情「本机显示设置」卡、`utils/displayScale*.ts`、「换算显示 ×倍率」标识。旧 `display-scale:<账号>:*` 记录不再参与计算；首页首次进入时清掉当前账号的旧记录并提示一次去罐表设置启用虚拟罐表。不把倍率自动转成罐表。
- **虚拟罐表**：罐表设置生成罐表后，管理员可「启用为虚拟罐表」→ 选首页当前油站设备的实际罐 → 确认（说明只在本机、不改设备）→ 存本机。罐表设置页在「设备当前罐表」下方单独显示「本机虚拟罐表」（来源、尺寸、点数/末点、启用时间、停用）。首页与详情的容积、质量、空容、水体积按虚拟表计算，标「虚拟罐显示」，详情给出设备原值。
- **数字键盘**：参数编辑器所有数值框改用支持小数点的数字键盘；带符号字段的负号不进输入框，由 ± 控制并显示在框前。
- **首页排版**：五项读数与左侧标签同字号、同字重，完整读数单行显示。

## Impact
仅客户端（miniapp）。新增 `utils/virtualTable.ts`（纯规则）、`utils/virtualTableStore.ts`（wx.storage）；改 `utils/telemetry.ts`、首页、罐详情、罐表设置两页、`components/param-editor`、`utils/remoteConfig.ts`、三语文案。不新增云端存储/API、数据库迁移或控制命令；「保存到控制器」（#49）流程不变。

## Non-goals
- 不跨手机、跨账号或向员工共享虚拟表（实施假设，见 design；若需共享须先定云端持久化与查看范围）。
- 不修改设备罐表、原始遥测、报警判断、历史记录、报表与导出；启用虚拟表不产生任何设备写入。
- 不宣称虚拟表等于计量校准：按几何尺寸生成的表是模型计算。
