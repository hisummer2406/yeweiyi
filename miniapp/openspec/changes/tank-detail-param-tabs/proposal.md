# 罐详情增加参数页签（Issue #43）

## Why
修改某个罐的修正参数要离开罐详情、重新选罐、再手动「导入设备值」，步骤多且容易改错罐。

## What Changes
- 罐详情顶部增加「实时数据 / 参数修正 / 储罐设置」三个页签，共用顶部的油站·设备·罐号信息栏；页内不切罐，首页点哪个罐就显示哪个罐（用户 2026-11-14）。
- 参数修正与储罐设置改由同一个编辑组件 `components/param-editor` 实现：自动带入设备最近上报值、直接编辑、标出原值→新值、只提交改动字段、自动暂存草稿、单一主按钮「下发修改」、在原页显示处理结果。
- 设置页里的「参数修正」「储罐设置」旧入口继续可用，复用同一组件与同一套草稿/提交规则；不再默认打开第一个罐，也不再需要「导入设备值」。
- 储罐设置不再保留只存本机的字段：可下发的 7 项可编辑；密度、罐高、低温只读显示设备上报值；物料颜色、低水位、自由文本介质不再显示（设备无对应字段，用户 2026-11-14 决定）。

## Impact
仅客户端。复用 `GET /api/devices/:device/tank-settings`、配置命令 POST/GET（依据 cloud `docs/config-command-contract.md`、`internal/api/tanksettings.go`）及 #42 的拒绝原因展示；不需要云端或设备协议变更，不扩大可编辑字段、不放宽修正值范围。

## Non-goals（不在范围内）
- 不新增下发权限：员工只读，不显示编辑与下发。
- 不迁移旧的本机草稿（旧 `calibration-draft` 未按账号隔离；旧储罐草稿没有基准值，无法判断哪些是真实修改），旧草稿不再读取。
- 不改操作记录页、补录、罐表设置等其他页面。
