# 设计

核查基线：分支 `feat/43-tank-param-tabs`（37ea1f1，含 #43 罐详情页签）。

## 换算
- 乘倍率：`oilVolumeL`、`oilWeightKg`、`waterVolumeL`、`nullVolumeL`（同一体积口径用同一倍率，质量同倍率）。不乘：液位、水高、温度、油/水占比；液位填充按占比绘制，不受影响。
- `toTankViews` 在舍入前把这四项的原始值存入 `raw`；`applyScale(view, factor)` 每次都从 `raw` 计算并舍入（`round2`），所以重复应用不会叠乘，关闭即回到原始值。缺失值保持缺失（显示「—」），不补 0。
- `scaleTag`：'' = 原始口径；否则 `×1.5`，页面按语言加「换算显示」。

## 存储与权限
- key = `display-scale:<账号 uid>:<完整设备编号>#<实际罐号>`，值 `{enabled, factor}`；读回时校验形状，损坏即默认（×1、关闭）。默认配置直接删除记录。
- 角色与账号每次都从当前 token 取：只有 `platform_admin`、`customer_admin` 可读、可写、可应用；`customer_user` 与无 role 一律原始值、看不到设置卡。设备访问范围仍由云端决定（看不到的设备本来就进不了详情）。
- 登出不清（key 含账号，与 #43 参数草稿一致）：同一管理员重开小程序恢复；其他账号读不到。换机后新设备编号不同，自然回到默认。

## 交互
- 设置卡只在管理员且当前罐有数据时显示；标题行点击切换「显示/隐藏」（只展开收起）。
- 开关变化立即保存；倍率输入只改输入框和预览，失焦或键盘完成时校验：非法（0、负数、空、非数字、指数写法）显示错误且不改已生效配置；合法且与已存不同才保存。
- 输入框只在账号/角色/设备/罐变化或保存后重置，60 秒罐型轮询等刷新不覆盖正在输入的内容。
- 每次保存/恢复前重新检查权限；保存失败提示「保存失败，未保存到本机」，卡片回到已存值。
- 首页 `onShow` 重新读取，并对保留的旧读数从 `raw` 重新应用，返回首页即与详情一致。
