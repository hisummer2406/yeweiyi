## Decisions

- **设备值与草稿分开**：设备回报只读显示；草稿不会被自动覆盖，也不会被当作设备值。导入是显式动作。
- **只发差异**：以设备回报为基准，草稿里填写且不同的开放字段才进入 `args`；四级液位顺序用"回报 + 改动"合并检查，0 = 不启用。
- **原因在表单里填**：不用 `wx.showModal` 的 `editable`（基础库与 Donut 支持不一），原因是表单一行；确认框只列修改前后。
- **requestId**：每次点"下发"并确认生成一次，超时的"重试"复用；跳出页面就放弃（之后去操作记录查看）。
- **提交后跳到操作记录页**（`issue-command?device=&commandId=`），该页跟踪进度与回显、列出最近命令；页面隐藏时 `onHide` 停止轮询，`onShow` 恢复。
- **补录**：时间 = 日期 + 时分（本地时区 → RFC 3339），不得晚于现在；`requestId` 每次确认生成；重放 200 视为成功。
- **员工**：`isReadOnlyRole` 为真时不显示下发/补录按钮，云端仍是边界。
