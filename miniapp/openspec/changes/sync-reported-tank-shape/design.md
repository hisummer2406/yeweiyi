# Design

- 设备配置与遥测独立读取，客户端按完整设备编号和实际罐号匹配，罐列表由当前可见遥测决定。
- API 类型以 cloud/internal/api/tanksettings.go 为准（核查 17fcde8）。配置类型已对齐；后台移除遥测结构中过时的字符串罐型预留项，小程序不改遥测线协议类型。
- 展示层 utils/tankShape.ts 区分已知、未知、临时读取失败和对象不可访问。临时失败可保留已知配置并标注，401/403/404 清除罐型缓存；上报时间沿用配置时间。
- 后台 useTankShapes 只读分页当前设备，沿用请求并发上限，60 秒复核；小程序首页与详情复用配置读取，每分钟复核、恢复或手动刷新时重读。对象变化及旧响应以页面代次、设备和账号校验隔离。
- 立罐素材复制自 android 的 min_oilcan.png，保留源图，按透明范围用 CSS 视口适配；分别定义卧罐和立罐填充窗口。小程序首页罐型未确认时保留原有通用罐图及液位并明确标注“通用示意图”，真实罐型状态仍为未知。
- 保持现有液位输入、油水层次和探针／报警状态规则。小程序四罐布局及字号不改，详情仅增加罐型和配置上报时间文字。

## Verification
运行仓库规定检查；浏览器使用合成数据检查实际组件／WXML 与样式。微信开发者工具、微信真机、Donut 和真实设备现场改型闭环需分别验收，不能以浏览器预览替代。
