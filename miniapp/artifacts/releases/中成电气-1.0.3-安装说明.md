# 中成电气 Android 1.0.3 安装说明

安装文件：`com.zhongchengelec.yeweiyi-1.0.3.apk`，版本号 103。

1. 把 APK 传到安卓手机后，在文件管理器中打开。若文件名被追加 `.1`，先改回 `.apk` 后缀。
2. 系统提示时，允许当前文件管理器安装未知来源应用，然后按提示安装。
3. 已安装同包名旧版时直接覆盖安装，保留旧应用，不要先卸载。已核验包名、原公司证书与版本号，实际覆盖升级仍待手机验证。
4. 用云平台已开通的账号和密码登录；本 App 不依赖微信登录。首次打开请确认首页、记录、语言切换和扫码功能。

支持 Android 7.0（API 24）以上的 arm64-v8a 设备。连接线上服务 `https://api.zhongchengelec.com`。

本包通过代码检查、APK v2/v3 签名和 ZIP 完整性校验；尚未做本版本真机验收。Donut 免费版水印和西班牙语未人工校对的限制仍保留。

签名证书保留在本机原位置 `~/yeweiyi-keystore/yeweiyi-release.p12`。后续更新必须继续使用同一证书；密码不在此说明或代码仓库中。
